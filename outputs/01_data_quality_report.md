# 数据质量体检报告（Step 1）

数据源：GiveMeSomeCredit 训练集，150,000 行 × 12 列


## 1. 目标变量分布

- 坏客户（target=1）：10,026 人，坏账率 **6.68%**
- 好客户（target=0）：139,974 人
- 不平衡比：约 14 : 1（建模时需要处理，策略岗常用分层抽样或权重）


## 2. 缺失值

- **monthly_income**（月收入）：缺失 29,731（19.8%）
- **n_dependents**（家属人数：负担系数）：缺失 3,924（2.6%）

> 处理决策：月收入缺失→用中位数填充并加缺失标记列；家属缺失→填0（无家属是合理值）


## 3. 异常值（业务规则体检）

- **age**：年龄超出[18,100]，14 条（0.01%）
- **revolving_utilization**：额度使用率>100%（理论上不该有，业务上常截断为1），3,321 条（2.21%）
- **monthly_income**：月收入=0（失业？还是数据问题？），1,634 条（1.09%）
- **n_loans_90d**：90天逾期笔数≥90（极端值，可能是逾期次数连记），269 条（0.18%）

## 4. 字段字典（业务语义）

| 字段 | 业务含义 |
|---|---|
| user_id | 主键 |
| target | 目标变量：1=未来2年内逾期90天+（坏客户） |
| revolving_utilization | 信用卡额度使用率：总额度用掉了多少（风控第一敏感特征） |
| age | 借款人年龄 |
| n_loans_30_59d | 30-59天逾期笔数：短期逾期的信号 |
| debt_ratio | 负债率：每月还债支出/月收入（含赡养） |
| monthly_income | 月收入 |
| n_credit_lines | 开放信贷/贷款笔数：信用活跃度 |
| n_loans_90d | 90天+逾期笔数：严重逾期信号 |
| n_real_estate_loans | 不动产/担保贷款笔数：资产背书 |
| n_loans_60_89d | 60-89天逾期笔数 |
| n_dependents | 家属人数：负担系数 |
