# 数据质量体检报告（Step 1）

数据源：GiveMeSomeCredit 训练集，150,000 行 × 12 列


## 1. 目标变量分布

- 坏客户（target=1）：10,026 人，坏账率 **6.68%**
- 好客户（target=0）：139,974 人
- 不平衡比：约 14 : 1（建模时需要处理，策略岗常用分层抽样或权重）
> 📌 分析结论：坏账率 6.68% 是全流程的基线数字——step2 的每张验证表、step3 的切档表都围绕它读偏离；约 14:1 的不平衡决定建模口径（分层切分 + class_weight 加权），评估看 KS/AUC 而不是准确率（全猜'好'也有 93% 准确率，无区分意义）。


## 2. 缺失值

- **monthly_income**（月收入）：缺失 29,731（19.8%）
- **n_dependents**（家属人数：负担系数）：缺失 3,924（2.6%）

> 📌 处理决策与理由：月收入缺失 19.8% 占比大且收入右偏——均值被高收入拉偏，**中位数稳健**；同时加缺失标记列，因为'没填'本身可能是信号（自雇/不配合/不愿暴露财务状况），直接填充会抹掉这层信息，标记列保留它、有没有预测力交给后续 IV 裁决。家属缺失仅 2.6% 且'无家属'（单身）是真实取值，缺失大概率就是'没有'的表达——填 0 语义自然。**同一个'缺失'，处理力度跟着业务含义走，不搞一刀切。**


## 3. 异常值（业务规则体检）


> 📌 分析结论（逐条）：年龄超界是**数据错误**（未成年人不可能合法申请信贷）→ step2 剔除；额度使用率>100% 业务上不可能（透支超过额度），多为统计时点错位的**口径瑕疵** → 截到 1（100%）保住样本；月收入=0 的 1,634 条保留不动（'失业报 0 收入'在业务上真实存在，不是错误值）。清洗方式的取舍逻辑：**数据错误的样本删掉，口径瑕疵的样本修正保留**。

> 🔍 96/98 判定的完整证据链：官方字典没有写清口径（字段主语是'借款人'，单账户还是跨账户合计未说明，且 30-59/60-89 两档定义带 'in the last 2 years' 而 90+ 档没有——字典自身不一致），所以判定不依赖口径推理，拿数据形态说话，三重证据：**①断层**——正常取值 0~17 连续衰减，18~95 零样本，96/98 与正常分布完全断开；**②孤立**——96 只出现 5 次、98 出现 264 次，真实的计数分布不会恰好孤立在两个值上；**③三字段同步**——这 269 条在 30-59 档和 60-89 档的取值也是同款 96/98，三档同时取这种值的概率为零，是同一错误源的系统性采集错误（连记或溢出）。**处理**：step2 统一修正到正常上界 17（观测到的正常最大值，零误伤、修正位置有数据支撑）。

- **age**：年龄超出[18,100]，14 条（0.01%）
- **revolving_utilization**：额度使用率>100%（理论上不该有，业务上常截断为1），3,321 条（2.21%）
- **monthly_income**：月收入=0（失业？还是数据问题？），1,634 条（1.09%）
- **n_loans_90d**：90天逾期笔数≥90（极端值，可能是逾期次数连记），269 条（0.18%）

## 4. 字段字典（业务语义）

| 字段 | 业务含义 |
|---|---|
| user_id | 主键 |
| target | 目标变量：1=未来2年内逾期90天+（坏客户） |
| revolving_utilization | 信用卡额度使用率：总额度用掉了多少（风控第一敏感特征） |
| age | 借款人年龄 |
| n_loans_30_59d | 30-59天逾期笔数：短期逾期的信号 |
| debt_ratio | 负债率：每月还债支出/月收入（含赡养） |
| monthly_income | 月收入 |
| n_credit_lines | 开放信贷/贷款笔数：信用活跃度 |
| n_loans_90d | 90天+逾期笔数：严重逾期信号 |
| n_real_estate_loans | 不动产/担保贷款笔数：资产背书 |
| n_loans_60_89d | 60-89天逾期笔数 |
| n_dependents | 家属人数：负担系数 |
