## 评分切档（A/B/C/D，测试集）

| 档位 | 分数区间 | 客户数 | 占比 | 坏账率 | 平均分 |
|---|---|---|---|---|---|

> 📌 切档表怎么读（梯度检查）：档位间坏账率 D>C>B>A 递减，梯度越陡=分数区分力越强；本表 D 档 37.37% 对 A 档 1.52% 约 25 倍——区分力极强，分数的区分力实打实落在了档位上（面试直接报这组数）。若相邻档坏账率接近甚至倒挂=该档位没区分力，切点要重定。

## 决策树规则挖掘（max_depth=3，训练集拟合）
```text
|--- total_late_cnt <= 0.50
|   |--- revolving_utilization <= 0.32
|   |   |--- age <= 57.50
|   |   |   |--- class: 0
|   |   |--- age >  57.50
|   |   |   |--- class: 0
|   |--- revolving_utilization >  0.32
|   |   |--- revolving_utilization <= 0.67
|   |   |   |--- class: 0
|   |   |--- revolving_utilization >  0.67
|   |   |   |--- class: 1
|--- total_late_cnt >  0.50
|   |--- total_late_cnt <= 1.50
|   |   |--- revolving_utilization <= 0.50
|   |   |   |--- class: 0
|   |   |--- revolving_utilization >  0.50
|   |   |   |--- class: 1
|   |--- total_late_cnt >  1.50
|   |   |--- n_loans_90d <= 0.50
|   |   |   |--- class: 1
|   |   |--- n_loans_90d >  0.50
|   |   |   |--- class: 1

```

> 📌 规则怎么读：决策树挖出的是可读的「如果…那么…」硬规则，可直接落到审批系统当拒绝线——典型路径如「总逾期次数>0.5 且 额度使用率>0.67 判坏」；每片叶子最少 2,000 样本，防过拟合出碎片规则；**仅训练集拟合**——测试集信息不许进规则（与建模同一泄露纪律）。
